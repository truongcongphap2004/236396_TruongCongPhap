## 1. Cấu trúc Dự án
- **Backend:** Node.js, Express.js, Mongoose (MongoDB Atlas)
- **Frontend:** HTML5, CSS3, JavaScript ES6 (Fetch API)
- **Cơ sở dữ liệu:** MongoDB Atlas

---

## 2. Danh sách các API Endpoints
- `GET /api/foods`: Lấy danh sách tất cả món ăn (Hỗ trợ tìm kiếm query `?search=`)
- `POST /api/foods`: Thêm món ăn mới
- `PUT /api/foods/:id`: Cập nhật thông tin món ăn theo ID
- `DELETE /api/foods/:id`: Xóa món ăn theo ID
